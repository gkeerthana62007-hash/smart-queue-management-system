# Smart Queue Management System
A web-based Smart Queue Management System designed to reduce waiting time and manage queues efficiently using digital token generation and real-time queue tracking.
## Feature
- Digital token generation
- QR-based token access
- Real-time queue tracking
- Automatic token numbering
- Waiting time management
- Queue status monitoring
- Simple and user-friendly interface
## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON
- QR Code
